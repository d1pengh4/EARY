## A. 정확도·성능

### A1. 오탐이 많지 않나요? 정상 전화에 경고가 뜨면 아무도 안 씁니다.
**정상 통화 10편에서 오탐 0건입니다.** 병원 예약, 택배, 은행 대출 승인, 진짜 검사실 연락, 통신사 요금 상담 같은 "기관이 전화하는 정상 통화"를 일부러 넣었습니다.
- 위험 단계는 AI가 아니라 규칙이 정합니다. 기관 이름만으로는 경고하지 않고, 송금·인증정보·앱 설치 같은 **행동 요구**가 다른 신호와 함께 나와야 최종 경고입니다.
- 실제 테스트에서 진짜 검사 연락을 사칭으로 판단한 오류를 찾아 고쳤고, 그 대화를 회귀 세트에 넣어 다시 생기지 않게 했습니다.
- 솔직한 한계: 회귀 세트는 팀이 쓴 대화라서 실제 통화보다 유리합니다.

### A2. 사기는 얼마나 잡나요?
**사기 대화 9편 모두 주의 이상으로 잡았고, 6편은 최종 경고까지 갔습니다.** 최종 경고가 안 된 3편 중 2편(가족 사칭, 대출 선입금)은 송금 요구는 잡았지만 함께 나온 신호가 하나뿐이라 규칙상 "주의"에 머물렀고, 1편은 사칭 초반부만 있는 대화입니다. 경고를 일찍 올릴수록 오탐이 늘기 때문에 지금은 보수적으로 둔 상태입니다.
- 실제 보이스피싱 녹음 3편으로도 시험했습니다. 처음엔 셋 다 놓쳤고, 원인(검찰 사칭 특유의 표현, 긴 문장에서 Jev가 신호를 지우는 문제)을 고쳐서 검찰 사칭 녹음은 지금 "주의"로 잡습니다.

### A3. 얼마나 빠른가요?
**상대 말이 끝나고 약 0.9초 안에 위험 단계가 바뀝니다.** 그중 0.66초는 음성 인식이 문장을 확정하는 시간이고, 확정된 문장에서 판단까지는 중앙값 0.19초입니다.
- 규칙(L0) 1ms 미만 → Jev 0.2초 → Groq 정보 추출 0.36초가 병렬로 돕니다.
- 웹 검색처럼 느린 일은 비동기라서 경고를 늦추지 않습니다.

### A4. STT가 틀리면요? 실제 녹음은 엉망일 텐데요.
**틀린 인식을 전제로 설계했습니다.**
- "2026 현제 4만 8271호" → `2026형제48271호`처럼 자주 틀리는 형태를 규칙으로 바로잡고, 기관명은 한 글자 틀려도 찾습니다.
- 사용자가 자막을 고치면 그 문장만 다시 판단하고, 잘못 뽑힌 정보는 지도에서 지웁니다.
- 실제 녹음에서 "씨캡탈", "공문장"처럼 인식이 크게 틀린 경우는 아직 약점입니다.

### A5. 스피커폰 한 대로 누가 말했는지 어떻게 구분하나요?
**내 목소리 등록 + 전화 음질 + 말의 내용, 세 가지를 같이 봅니다.**
- 애국가 1절을 10초 읽어 내 목소리를 등록합니다. 전화를 거친 상대 목소리는 고음이 잘리는 특성이 있어 이것으로 구분합니다.
- 소리로 확신이 낮으면 Jev가 말의 내용("전화를 건 쪽인가")으로 다시 판단하고, 사용자가 고치면 학습합니다.
- 솔직한 한계: 합성 음성으로는 10/10이지만, 실제 스피커폰 녹음으로 기준값을 맞추는 작업은 진행 중입니다. PC 통화는 채널이 나뉘어 이 문제가 없습니다.

## B. AI 설계

### B1. 왜 LLM 하나로 하지 않고 여러 단계로 나눴나요?
**하나의 LLM은 느리고, 틀릴 때 위험하기 때문입니다.**
- 큰 LLM 한 번 호출이 1~3초라 통화 중에는 늦습니다. 그래서 빠른 판단은 규칙과 Jev(정해진 질문에 확률로만 답하는 모델)가 하고, 자유로운 추출만 Groq가 합니다.
- 각 단계가 못 하는 일을 정해 뒀습니다. 예: Groq는 사건번호·금액·날짜를 새로 만들 수 없습니다. 실제로 사건번호를 지어낸 적이 있어서 막았습니다.

### B2. AI가 "보이스피싱입니다"라고 단정하면 책임 문제가 생기지 않나요?
**단정하지 않도록 코드로 막았습니다.**
- 위험 단계는 규칙이 정하고, AI가 만든 문장은 "보이스피싱입니다" → "의심돼요"로 바꿉니다. 바꿀 수 없으면 버립니다.
- 검색 결과로 신원을 확인했다고 말하지 않습니다. "본인 확인 안 됨"으로 표시하고 대표번호로 다시 거는 방법을 보여 줍니다.
- 이어리는 대신 신고하거나 송금을 막지 않습니다. 판단을 돕고 결정은 사람이 합니다.

### B3. AI가 엉뚱한 번호를 알려 주면요?
**검증된 공식 번호(112, 1332, 1301 등) 외의 번호는 화면과 답변에서 모두 지웁니다.** 실제 테스트에서 AI가 업체 번호를 "공식 대표번호"라고 안내한 일이 있어서 만든 장치이고, 특수 하이픈으로 쓴 번호까지 잡습니다.

### B4. API가 끊기거나 한도가 차면요?
**빠른 판단은 규칙만으로도 동작합니다.** 회귀 세트 19편은 API 키 없이 규칙만으로도 모두 통과합니다.
- Jev는 0.6초 안에 답이 없으면 건너뛰고(차단기), 보드 에이전트는 Groq → Gemini로 자동 전환합니다.
- 시연은 외부 응답을 녹화해 둔 카세트로 네트워크 없이도 똑같이 재생할 수 있습니다.

## C. 개인정보·법

### C1. 통화를 녹음하는 건 문제가 없나요?
**통화 당사자가 자기 통화를 듣고 판단을 돕는 구조이고, 음성 원본은 저장하지 않습니다.**
- 저장하는 것은 자막·근거·리뷰뿐이고 기본 7일 뒤 지워집니다(보관 기간 설정 가능, 즉시 삭제 가능).
- 화면에 "녹음 고지됨" 표시가 있습니다.
- 솔직한 한계: 음성은 STT를 위해 외부 API(RTZR)로 전송됩니다. 실제 서비스 전에는 녹음 고지·보관 정책의 법률 검토가 필요합니다. *(통신비밀보호법 관련 설명은 발표 전 팀이 확인)*

### C2. 신고할 때 개인정보가 새지 않나요?
**신고 준비안은 이름·계좌번호·연락처를 자동으로 뺍니다.** 피해 여부는 사용자가 직접 고르고, 이어리는 대신 접수하지 않습니다.

## D. 차별성·확장

### D1. 통신사나 보안 앱에도 보이스피싱 탐지가 있지 않나요?
**이어리는 "위험해요" 알림에서 끝나지 않고, 왜 위험한지와 무엇을 확인해야 하는지를 통화 중에 그림으로 보여 줍니다.**
- 사건 지도(누가, 무엇을, 어떤 근거로), 들은 말과 공식 자료 대조, 지금 할 일 결정 나무.
- 사기만이 아니라 요금 상담처럼 정상 통화에서도 금액·약정·위약금을 정리해 줍니다.
- *(경쟁 서비스의 구체 기능은 발표 전 팀이 최신 정보로 확인)*

### D2. 사기 수법이 바뀌면요?
**새 수법은 규칙 파일(YAML)과 도메인 팩을 추가하면 바로 반영되고, 규칙에 없는 표현은 Jev와 Groq가 받쳐 줍니다.** 이번에도 실제 녹음에서 놓친 표현을 찾아 하루 안에 추가했고, 회귀 세트로 기존 판단이 깨지지 않았는지 확인합니다.

### D3. 어르신이 이걸 쓸 수 있나요?
**통화 중에는 화면 맨 위 "다음 행동" 한 줄만 보면 되게 했습니다.** 예: "송금하지 마세요", "원래 알던 가족 번호로 다시 걸기". 나머지 그림은 보호자나 통화 후 리뷰용입니다. *(실제 사용자 테스트는 아직 없음)*
