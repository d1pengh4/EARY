## 해석할 때 주의할 점
- 회귀 세트 19편은 팀이 직접 쓴 대화다. 실제 통화보다 문장이 깔끔하고, 규칙을 만든 사람이 쓴 문장이라 유리하다.
- 지연은 글 입력 기준이다. 실제 통화는 여기에 STT 확정 시간(말 끝 + 약 0.66초)이 더해진다.
- 실제 녹음으로 확인한 것은 3편뿐이다. STT 오인식("씨캡탈", "공문장")이 많은 실제 음성에서의 탐지율은 아직 충분히 재지 못했다.
